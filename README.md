# Цикл A–D

Приложение для тренировок по циклу A → B → C → D: упражнения с фото, журнал тренировок по датам, мерки и график. Работает без интернета и без аккаунтов. Записи хранятся только на устройстве.

В архиве две формы одного и того же приложения:

- `docs/` — веб-версия. Это готовые файлы, собирать их не нужно.
- `android/` — Android-проект, который показывает ту же веб-версию внутри приложения и собирается в APK.

## Способ 1. APK через GitHub, без Android Studio

Подходит, если на компьютере нет Android Studio.

1. Создай на GitHub репозиторий и загрузи в него содержимое этой папки (ветка `main`), так чтобы папки `.github`, `android` и `docs` лежали в корне репозитория.
2. Сборка «Android APK» запустится сама после загрузки. Следить за ней можно во вкладке **Actions**; там же её можно запустить вручную кнопкой **Run workflow**.
3. Через несколько минут в разделе **Releases** появится файл `cycle-ad.apk`. Тот же файл лежит в результатах сборки под именем `cycle-ad-apk`.
4. Скачай APK на телефон и открой его. Android попросит разрешить установку из этого источника.

Если репозиторий публичный, его содержимое и APK видны всем. В тексте плана есть твой вес и мерки, поэтому репозиторий лучше сделать приватным: **Settings → General → Change repository visibility**.

## Способ 2. APK через Android Studio

1. Открой в Android Studio папку `android/`.
2. Дождись синхронизации Gradle и нажми **Run** с подключённым телефоном.

Либо из терминала (нужны JDK 17+ и Android SDK):

```
cd android
./gradlew assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Способ 3. Без APK: сайт, который ставится как приложение

Папку `docs/` можно положить на любой хостинг статических файлов. На GitHub: **Settings → Pages → Deploy from a branch → main, /docs**. Затем открой адрес сайта в Chrome на телефоне и выбери в меню «Установить приложение» или «Добавить на главный экран». После первого открытия оно работает офлайн.

Важно: бесплатный GitHub Pages работает только для публичных репозиториев, и сайт виден всем, у кого есть ссылка. В тексте плана есть твой вес и мерки. Если это не подходит, используй способ 1 или 2.

## Данные

- Записи хранятся на телефоне внутри приложения. Если удалить приложение или очистить его данные, записи пропадут.
- Резервная копия: вкладка **План → Резервная копия → Скопировать записи**. Текст можно сохранить в заметках и вставить обратно кнопкой «Восстановить из текста». Так же записи переносятся на другой телефон или из сайта в APK.
- Все сборки подписаны одним ключом `android/app/cyclead.jks` (пароль лежит в `android/app/build.gradle`). Поэтому новая версия APK ставится поверх старой и записи сохраняются. Ключ не секретный, для публикации в магазине он не годится.

## Как менять содержимое

Всё приложение — один файл `docs/index.html`, фото лежат в `docs/img/`. После правок запусти `./sync-web.sh`: он копирует `docs/` в Android-проект. Сборка на GitHub делает это сама.

## Что проверено

- Веб-версия проверена в Chromium на ширине телефона: отметка тренировок, мерки, график, работа без сети, резервная копия, открытие с диска.
- Android-проект в этой среде не собирался и на устройстве не запускался: серверы с Android SDK здесь недоступны. Код экрана проверен компилятором, файлы манифеста и ресурсов — на корректность XML. Версия плагина сборки — 8.11.1, Gradle — 8.14.3; если Android Studio предложит обновить их, соглашайся.
